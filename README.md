# Null Breach

LOGO

## What is Null Breach

Null Breach is a Minecraft mod that adds a new sci-fi/fantasy traversal mechanic to spice up your playthroughs.

## Description

You can craft a new item called the Null Breach Device (NBD), when activated it tears a hole in the fabric of space-time. This forcefully pulls you into what is known as the Null.

When inside the Null you can move pretty much wherever, but be warned, the Null is intrinsically unstable. The NBD stabilises the Null for a short period of time, after which the NBD pushes you out of the Null before it consumes you. 

## Feature List

- Null Breach Device that allows you to traverse the Null.
- Multiple upgrades that can alter how your personal NBD functions. (Future)
- The Nullifier block that when placed, disrupts any NBDs in its Area of Effect. (Future)
